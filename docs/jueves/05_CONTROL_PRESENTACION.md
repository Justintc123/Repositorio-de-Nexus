# 05 - Control y presentación

Este archivo es para quien quede libre o para que lo use Santi al final.

Tu tarea es probar, anotar errores y ayudar con la presentación.

## Pruebas rapidas

Probar estas pantallas:

- Inicio.
- Mensajes.
- Trabajos.
- Boletin/notas.
- Preceptoria/toma de lista.
- Documentos.
- Nexus diagnóstico.

## Demo recomendada

La presentación deberia durar 5 a 7 minutos.

Orden:

1. Mostrar A.R.Y.O.S como alumno.
2. Abrir trabajos.
3. Abrir boletin por trimestre.
4. Entrar como docente y mostrar carga de notas.
5. Entrar como preceptor y mostrar asistencia.
6. Mostrar mensajes.
7. Mostrar Nexus con diagnóstico.
8. Mostrar hardware/PCB/carcasa.

## Frase de inicio

```text
Nexus es la central técnica y A.R.Y.O.S es el campus escolar. El sistema une
asistencia, notas, trabajos, mensajes y hardware RFID en una plataforma local.
```

## Frase de cierre

```text
La idea es que la escuela tenga un sistema propio, modular y ampliable, que
funcione localmente y pueda crecer a dominio, app y hardware real.
```

## Anotar errores

Si algo falla, anotarlo aca:

```text
nexus_core/docs/ERRORES_JUEVES_NEXUS.md
```

Formato:

```text
Hora:
Quien:
Pantalla:
Que se quiso hacer:
Que fallo:
```

## Regla simple

Si algo no sale despues de 10 minutos, anotarlo y seguir con otra parte de la
demo. No arruinen la presentación intentando arreglar todo a último momento.
