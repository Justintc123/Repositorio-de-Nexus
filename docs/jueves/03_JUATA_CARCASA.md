# 03 - Juata: carcasa RFID

Tu tarea es avanzar con la carcasa donde va el sistema RFID.

## Objetivo

Que el sistema no parezca un prototipo tirado sobre la mesa. Tiene que tener una
forma clara: lector, pantalla, cables y placa con lugar definido.

## Checklist

Revisar que entren:

- lector RFID;
- pantalla;
- cables Dupont;
- placa/PCB;
- alimentación o USB;
- tornillos, encastres o tapa.

## Cosas importantes

El lector RFID tiene que quedar cerca de la superficie para que lea bien la
tarjeta.

La pantalla tiene que quedar visible.

Los cables no tienen que quedar aplastados.

Tiene que haber forma de abrir o revisar adentro si algo falla.

## Durante las 4 horas

1. Abrir el modelo.
2. Corregir medidas que no cierren.
3. Dejar espacio para lector y pantalla.
4. Preparar una captura o vista 3D para la presentación.

## Para presentar

Preparar una frase corta:

```text
La carcasa ordena el hardware y permite que el lector RFID quede fijo,
protegido y listo para usar en un aula.
```
